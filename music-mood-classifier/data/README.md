Place your audio files in this folder using the following structure:

data/
  your-dataset/
    happy/
      track1.wav
      track2.wav
    sad/
      song1.wav
      song2.wav
    energetic/
      file1.wav

Notes:
- If librosa is not available, only .wav files are supported by the scripts.
- Standardize audio to mono 22050 Hz for best results and faster processing.
